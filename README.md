# FS25 Hand Spreader

A hand spreader that can be used to spread fertilizer, lime, and salt. It is very inexpensive compared to larger machines and is suitable for cost-effective de-icing or applying lime or fertilizer in a small yard.

## Origin and fork

`FS25_HandSpreaderRD` is a fork of [Hand Spreader by Andi Modding on ModHub](https://www.farming-simulator.com/mod.php?mod_id=309228&title=fs2025).

The fork changes the following:

1. Added `isCareWheelConfiguration=“true”` to the wheel configuration to prevent damage to crops.
2. The position of the `exactFillRootNode` area has been adjusted to allow manual filling of the spreader, such as with materials from the [Hand Liftable Consumables](https://www.farming-simulator.com/mod.php?mod_id=316312&title=fs2025) mod.
